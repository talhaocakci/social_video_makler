# GetFluentFast Pronunciation Curriculum v1 — English, Spanish, German

Status: authored production blueprint; pilot modules are local previews only.

## Learner-facing contract

- Target languages: English, Spanish, German only.
- Every learner-visible card and every spoken token is in the target language.
- No translation, guiding language, narration, explanation, instruction, or call to action.
- Card structure: grapheme or spelling pattern → IPA → example word → word IPA.
- Each word is synthesized once, then the exact lossless utterance is repeated exactly twice with a 650 ms pause.
- One spelling-sound contrast per short module; two examples per realization where practical.
- Dialect or standard is fixed per module. Dialect-dependent contrasts are never mixed silently.
- Rare loanwords, proper names, morphology-driven alternations, and lexical exceptions are separate exception modules.
- Every module requires source review, machine language/source validation, and native-speaker audition before release.

## Teaching sequence

Each language follows its own frequency and difficulty order:

1. Hear and notice one spelling-sound mapping.
2. Contrast it with the closest confusable mapping.
3. Imitate two high-frequency examples per mapping.
4. Recycle the mapping in later short-context material.

The catalog below is a bounded v1 coverage target for productive adult pronunciation. It covers the core alphabetic code and high-value spelling alternations; it does not claim that every spelling of every loanword in the language is regular.

## Release gates

For every module:

1. Editorial source record includes language, locale, variety, CEFR, grapheme, IPA, word, word IPA, focus span, and evidence URLs.
2. Validator rejects any non-null guiding language and any repetition count other than two.
3. TTS input contains only the example word; no hidden spoken labels or instructions.
4. Final repeated clip is assembled from two byte-identical copies of one normalized lossless utterance.
5. Automatic checks cover source checksum, locale, ASR word match, speaker consistency, silence trimming, audio/video stream presence, dimensions, duration, and three visual checkpoints.
6. A qualified native speaker auditions every final word clip. Machine QA cannot waive this gate.
7. Release, feed ingestion, and social publishing remain disabled until separately approved.
